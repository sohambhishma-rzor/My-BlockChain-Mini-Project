## Academic Certificate Verification
A blockchain-based academic certificate verification system using Solidity, Remix IDE, Web3.js, Ethers.js, and MetaMask.

 The system allows an authorized institution/owner to:
1)Issue academic certificates

2)Verify certificates using a unique certificate ID

3)Revoke certificates when required

4)Store certificate information on a blockchain smart contract
